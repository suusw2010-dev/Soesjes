# 🎮 Soesjes Arcade

## Beschrijving

Soesjes Arcade is een arcadewebsite waarop gebruikers verschillende spellen kunnen spelen vanuit één centrale homepage.

De website bevat:

- Neon Soesjes Catch
- Boter, Kaas en Eieren
- Kleuren Klikken
- Airhockey
- Een Unity-spel

Vier spellen zijn gemaakt met HTML, CSS en JavaScript. Eén spel is gemaakt in Unity.

# Domein 2: Interactie

## Gebruikersonderzoek

We hebben meerdere gebruikers de website laten testen.

1. Kies een spel.

3. Speel een ronde.
4. Keer terug naar de homepage.

# Domein 3: Gamedesign (Unity-spel)

## Genre

Arcadegame.

## Wat maakt het spel leuk?

Het spel vereist snelle reacties en daagt spelers uit om hun score te verbeteren.

## Unieke invalshoek

Het Unity-spel maakt deel uit van een grotere arcadeomgeving met meerdere spellen.

## Spelregels en mechanics

### Gameplay-loop

1. Start het spel.
2. Speel een ronde.
3. Verzamel punten.
4. Verbeter je score.

### Primary mechanics

- Bewegen
- Reageren
- Punten verzamelen

### Progressie

Spelers proberen steeds hogere scores te behalen.

## Stijl en sfeer

Het spel gebruikt dezelfde kleurrijke arcade-uitstraling als de rest van Soesjes Arcade.
